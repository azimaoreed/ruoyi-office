## 手工验收场景

### 1. 普通审批链路

- 发起流程，确认首节点正常生成待办
- 审批通过，确认后续节点按原配置流转
- 审批详情页检查操作记录、时间线、版本信息无异常

### 2. 驳回重走

- 使用固定节点驳回，确认生成新版本并重走后续节点
- 使用表达式目标驳回，确认不同变量命中不同目标节点
- 连续执行超过阈值的驳回重走，确认按配置阻断或转交流程管理员
- 检查审批日志中可看到超限次数、处理结果

### 3. 修改申请子流程

- 从主流程发起修改申请子流程，确认主流程冻结
- 子流程完成后按恢复策略继续或回退
- 主流程详情页确认父子流程关联信息、冻结状态、恢复结果正确

### 4. 协同操作

- 委派、转办、加签、减签分别执行一次，确认时间线与审批人变化正确
- 手工抄送用户、角色、部门，确认接收人去重后生效

### 5. 超时处理

- 分别配置自动提醒、自动同意、自动拒绝
- 分别配置自动转办、自动跳过、自动终止流程
- 检查超时后评论、日志、任务归属或流程状态符合配置

### 6. 原有能力回归

- 静态子流程照常发起和回收
- 审批人为空、审批人与发起人相同的兜底策略保持可用
- 旧流程定义不配置新字段时仍可正常部署、执行
